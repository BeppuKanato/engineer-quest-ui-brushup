# マスコット仕様

2026-11-20 作成。マスコットの画像を作る時の基準。生成の指示と、出来た画像の受け入れチェックの両方に使う。
役割と場面は `docs/design-policy.md` の3章を見る。

## 基準画

- 基準画は `public/images/mascots/red-panda/master.png`（現在の「通常」画像と同じもの）。新しい画像は、基準画をもとに編集して作る（テキストから毎回新規に描かせると、顔つきも色もブレるため）
- 画像を作り直す場合は、新しい「通常」画像を基準画（master.png）に差し替える
- マスコットはレッサーパンダ1体のみ。他のキャラクター（ペンギン・フクロウ）の画像は削除した
- 三面図（側面・背面）は作らない。アプリに出るのは常に正面で、側面と背面は使う場面がない。横向きのポーズが要る場面が出てきたら、その時に足す

## 見た目の仕様

- 全体：レッサーパンダ。頭が大きく体は小さい（約2.5頭身）、正面立ちが基本。塗りのあるイラスト調で、毛並みの見える柔らかい質感にする
- 毛と顔：
  - 毛は明るいオレンジ（#fb6b11 前後、陰影で #da4a08 くらいまで）
  - 耳は三角で先が少し丸い。外側は白っぽく、内側は濃い赤茶（#771b04）
  - 眉の上に白い模様が2つ。頬の横に白い毛の房。目の下から頬にかけて、濃い茶（#6c1d05）の模様が流れる
  - 口元は白（#fdf2e9 前後）。鼻は黒く小さい。目は大きく、濃い茶の瞳に白いハイライト
- ゴーグル：額の上に乗せる。レンズは青のグラデーション（水色から濃い青 #0153c9 の側へ）。縁は銀、ベルトは黒で頭の横に回る
- マフラー：濃い青（#143e97）。首元で結んで、端が横に流れる
- 服と道具：白いパーカー（#fdf9f5）。胸に茶色の道具ベルト2本と銀のバックル、前にポケット
- 下半身と手足：濃い茶（#4d2619〜#5a2917）
- しっぽ：体の左側に出る太いしっぽ。オレンジ（#d34205）と濃い茶（#71220c）の縞

色は、基準画（public/images/mascots/red-panda/master.png）から実測した値。塗りの陰影で幅があるので、中心の色の目安として使う。

## 作り方

- アニメーションは、アニメーションごとに差分のコマを新規に作る（例：跳ねる動きなら、踏み切り・空中・着地のコマ）。既存の状態画像を使い回して動きに見せるのではない
- 各コマは基準画をもとに編集して作る。体・衣装・しっぽの形と色はコマ間で同一に保つ
- 表情違いは、顔まわりの部分編集で作る
- 同じツール・同じ設定で作り、指示文と設定は画像と一緒に残す

## 受け入れチェック

- 色は、この仕様のコードと実測で照合する
- 次が変わっていたら作り直し：ゴーグルとマフラーの青、しっぽの縞、耳の内側の色、眉と頬の白い模様
- 最初から複数候補を出して、その中から選ぶ前提で作る
