# 全ページ棚卸しと進め方

2026-11-20 作成。対象は本体 develop 2f332c3 の front（このリポジトリの写し）。

## デザインの進め方

- 第1バッチで視覚言語（図・旗やバッジ・マスコットの動きで見せる、文字に頼らない）を決め、残りはそれに倣う
- 各画面は 2560×1440 と 1093×614 の2サイズでスクリーンショットを撮って確認する
- 決まった画面から、本体側に実装 Issue を切って移植する

## データの方針（2026-11-20 決定）

- 中身のデータ（単元名・実績名と説明・カード名とレアリティ・作る課題名）は**実データ**を使う。本体の seed から抽出した写しが `src/design/data/` にある（実績50件・知識カード21枚・コース10件・作る課題5件）
- 利用者の状態（進み具合・所持・連続学習日数・解除済み実績）は**仮**。「学習の中盤にいる人」を基準状態にする（単元2/7完了・3単元目が進行中・カード7/21・実績9件解除）
- 掲示板の投稿文のような利用者が書くものは仮の文面でよい
- デザインモード（`.env` で常時オン）では API を呼ばず、`src/design/fixtures.ts` のフィクスチャで描く。フィクスチャが無い GET はエラー表示になるので、画面をデザインする時にその画面の分を足す

| `/` | 未ログイン向けの案内ページ。実験の学習者が使う画面ではない |
